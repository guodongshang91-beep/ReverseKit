# 合法用途与授权边界

> 这份文档是给使用者看的操作边界，不是法律意见。涉及具体案件请咨询执业律师。

## 一、什么情况可以用

| 场景 | 需要的前提 | 说明 |
| --- | --- | --- |
| 自有资产测试 | 你是所有者 | 自己的域名、服务器、软件、网络，随便测 |
| 授权渗透测试 | **书面授权**（合同 / SOW / 授权书） | 授权范围要写清域名、IP 段、时间窗、允许的手法 |
| SRC / 众测平台 | 平台规则 + 目标在收录范围 | 平台规则即授权边界；超范围一样是未授权 |
| 教学与研究 | 隔离环境 / 靶场 | DVWA、Juice Shop、自建靶机 |
| 自有软件分析 | 你拥有或已获授权 | 含破解自己买的软件的授权校验，用于兼容/迁移 |
| 自有网络自查 | 你是网络所有者 | WiFi 自查只对自己的 AP |

## 二、什么情况不可以用

- 未获授权扫描、渗透、爆破任何第三方系统；
- 破解他人软件、绕过他人产品的授权与计费；
- 破解、蹭用他人 WiFi；
- 抓取、留存、传播他人个人信息与业务数据；
- 对目标做写入、删除、DoS、持久化等破坏性动作（即便在授权范围内，未写明即禁止）；
- 把工具用于「帮朋友看一下他公司网站」这类口头授权——口头授权在事后几乎无法举证。

## 三、授权范围内也要守的六条

即便有书面授权，下面六条仍然是硬约束：

1. **最小影响**：只读优先；证明所需的最小数据量；不整包下载业务数据。
2. **不碰生产数据**：需要证明可写入时，用无害标记（如 `test-<uuid>`）并立即清理。
3. **不扩大范围**：授权写了 `a.example.com`，就别去碰 `b.example.com`，哪怕同一个系统。
4. **不横向移动**：除非明确授权，拿到一台就停，别顺着内网继续。
5. **脱敏**：报告里的手机号、身份证、IMEI、内网 IP、用户标识一律打码。
6. **及时报告**：发现高危立即告知，不等报告写完；不公开披露，除非按约定走完流程。

## 四、常见误区

| 误区 | 事实 |
| --- | --- |
| "我只是扫了一下，没造成损失" | 未授权访问/扫描本身在多数辖区已构成违法，是否造成损失只影响量刑 |
| "公开的漏洞，谁都能测" | 漏洞公开不等于系统授权你测试 |
| "平台收录了这家厂商，所以都能打" | 平台规则通常限定资产范围与手法，超出即违规 |
| "我只是研究，不图钱" | 主观目的不改变行为的违法性认定 |
| "他自己网站有漏洞，活该" | 受害人过错不构成免责 |
| "我用的工具是开源的，所以合法" | 工具合法性 ≠ 使用行为合法性 |

## 五、法律依据（中国大陆，供参考）

- 《中华人民共和国刑法》第 285 条：非法侵入计算机信息系统罪；非法获取计算机信息系统数据、非法控制计算机信息系统罪
- 《中华人民共和国刑法》第 286 条：破坏计算机信息系统罪
- 《中华人民共和国网络安全法》第 27 条：不得从事非法侵入他人网络、干扰他人网络正常功能、窃取网络数据等危害网络安全的活动
- 《中华人民共和国数据安全法》《个人信息保护法》：数据处理与个人信息收集的合规要求
- 《中华人民共和国治安管理处罚法》相关条款：非法侵入计算机信息系统的行政处罚

其他辖区：美国 CFAA（18 U.S.C. § 1030）、英国 Computer Misuse Act 1990、欧盟 NIS2 与各国刑法对应条款。
**跨境目标要同时考虑目标所在辖区和你所在辖区的法律。**

## 七、如果你不确定

停下来，做这三件事：

1. 把授权文件翻出来，逐字读范围条款；
2. 把不确定的动作列成清单，发给授权方书面确认；
3. 在拿到书面回复前，**只做被动信息收集**（公开信息、证书透明日志），不动目标。

这三步花不了两小时，比事后解释便宜得多。
